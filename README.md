# GitLowers

**GitLowers** is a straightforward iOS app designed to search for GitHub usernames and display their followers. The app allows users to view a list of followers, see detailed information about each follower, and manage their favorites using UserDefaults.

Developed independently after following a tutorial by Sean Allen, GitLowers uses basic iOS components without advanced architectures or testing frameworks.

## Features

- Search for GitHub usernames to see their followers.
- View a list of followers and their basic details.
- Tap on a follower to view detailed information, including their name, profile picture, repositories, followers, and following count.
- Add or remove users from your favorites list.
- Access and manage a list of favorite users.
